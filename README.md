# AFTER12 — Independent Culture Festival

AFTER12 is a fictional music and culture festival based in Amsterdam, designed as a frontend development and web design project. The idea was to create a website that captures the feeling of a summer festival through its visuals, typography, and overall atmosphere, rather than making it feel like a standard event website.

The concept revolves around three days of live music, art, and late summer evenings. I wanted the design to feel warm, a little nostalgic, and editorial, with a visual identity that carries through the different pages.

## About the project

The website includes a landing page introducing the festival, an artist lineup section, an experience page, a festival schedule, and a ticket page. I focused on making the different sections feel connected while giving each page its own purpose.

Some of the things I worked on include:

- Creating a visual identity with a warm colour palette, expressive typography, and festival-inspired imagery.
- Building reusable React components and organizing the website into separate pages.
- Adding interactive artist cards with an expandable artist spotlight.
- Creating navigation between pages using React Router.
- Designing a ticket selection interface with ticket types, quantity controls, and a demo checkout confirmation.
- Adding hover effects, transitions, and responsive layouts for different screen sizes.

## Built with

- **React** — UI components and interactive features
- **JavaScript** — application logic and interactions
- **CSS** — layouts, responsive styling, animations, and visual design
- **React Router** — navigation between pages
- **Vite** — development server and build tooling
